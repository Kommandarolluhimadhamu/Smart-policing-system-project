My project is a Smart Policing System that uses advanced AI models like GPT and XLNet to help law enforcement make better decisions. It analyzes crime data, predicts possible incidents, and provides real-time insights to improve public safety. We combined traditional machine learning methods with powerful language models to improve accuracy and efficiency, while also considering privacy and ethical issues.
Data Collection: The system gathers crime-related data (such as past records, incident reports, location-based patterns).

OPERATING SYSTEM: Windows 7/8/10
•SERVER SIDE  SCRIPT: HTML, CSS, Bootstrap & JS
•PROGRAMMING LANGUAGE: Python
•LIBRARIES: Flask, Pandas, MySQL, Connector, Tensor flow, keras 
•IDE/Workbench: VS Code
•TECHNOLOGY: Python 3.8+
•SERVER DEPLOYEMNT:  Xampp Server
Models used:
GPT: AI model that understands and generates human-like text.
XLNet: An advanced model that better understands the context and order of words.
SVM: A machine learning model used for classifying data.
KNN: A model that makes predictions based on similar past data.
LLM (Large Language Model): AI trained on large text datasets to understand language and context.
